# Local IBM Plex fonts

Unmodified IBM Plex Sans Regular and IBM Plex Mono Regular WOFF2 files from
[IBM/plex](https://github.com/IBM/plex), under the SIL Open Font License 1.1 in
`OFL.txt`. Retrieved October 17, 2026. Embedded locally in the dashboard; no
font service or network access is required at runtime.

Source paths:

- `packages/plex-sans/fonts/complete/woff2/IBMPlexSans-Regular.woff2`
- `packages/plex-mono/fonts/complete/woff2/IBMPlexMono-Regular.woff2`
